# Игровые фактуры транспорта

Производные трёх сгенерированных поверхностей. [Источник, сервис и точные промпты](../../../../output/imagegen/vehicle-surfaces-2026-09-15/README.md).

Двенадцать PNG 512×512, суммарно 939144 байта:

- `paint-height.png`, `paint-roughness.png` — микрорельеф и неоднородность лакокрасочного покрытия.
- `rubber-height.png`, `rubber-roughness.png` — поры/мелкие канавки и матовость резины.
- `metal-height.png`, `metal-roughness.png` — мелкая направленная фактура металла.

Созданы `tools/prepare-vehicle-textures.py`: перевод в яркость, уменьшение, удаление плавной компоненты освещения, периодизация и сопоставление краёв, нормализация силы детали. Высота и шероховатость художественно выведены из изображений; это не сканы с измеренными физическими параметрами.

Все карты данных используют NoColorSpace, RepeatWrapping и дополнительную UV-развёртку `uv1`. Краска/металл повторяются 1,5 раза на метр проекции, резина — 2. На весь парк загружаются двенадцать общих Texture, готовых до создания игровых машин; цвет кузова и исходные цветовые атласы независимы. При ошибке загрузки остаются процедурные фактуры.

Карты подключены в `src/vehicle-materials.js`; их предзагрузка вызывается из `src/main.js` и `src/transport-review.js`. Процедурные fallback-модели сохраняют прежнюю микрофактуру краски.
