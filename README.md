# Web games

Browser games designed and built with AI tools (Claude Code, generated art and sound), made for Yandex Games and CrazyGames.

Play: https://brigadirfound.github.io/games/

- `not-a-sound/`: first-person horror, the stalker hunts by sound
- `ghostfire/`: voxel FPS, 1v1 against a recorded ghost player
- `gaff-ice-duel/`: 1v1 arcade duel on ice
- `autopark/`: merge idle with cars (Phaser 3)
- `sta/`: 3D open-world prototype (Three.js), UI in Russian

Third-party libraries keep their own licenses (three.js and Phaser: MIT). Vehicle models in `sta/` are CC BY 4.0, credits in `sta/transport-credits.html`. Game code and original assets: all rights reserved.
